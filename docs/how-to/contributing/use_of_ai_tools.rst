Use of AI tools
===============

You are welcome to use AI tools (code assistants, large language models) when
contributing to the library. If you do, the description of your pull request
must say which parts were AI-generated. Autocomplete and spelling fixes do not
count.

We also ask the following:

- You are responsible for your contribution: you should understand it, have
  tested it and be able to explain every line.
- Keep it small and self-contained. Generated code should be documented,
  readable and isolated (for example one strategy class plus its tests) so that
  it can be cleanly removed later. We will not accept large volumes of generated
  code.
- A new strategy should either come from the published literature, with a
  reference in the :ref:`bibliography`, or be qualitatively new. A generated
  variant of a strategy already in the :ref:`strategies-index` adds no value.
- The maintainers do not commit to maintaining AI-generated code, and we may
  remove it if it becomes a maintenance burden.
